========================================
HƯỚNG DẪN SỬA LỖI NHANH
========================================

Lỗi: "Host 'localhost' is not allowed to connect to this MariaDB server"

GIẢI PHÁP NHANH NHẤT:
========================================

BƯỚC 1: Dừng MySQL trong XAMPP Control Panel
----------------------------------------
- Mở XAMPP Control Panel
- Click "Stop" cho MySQL service

BƯỚC 2: Khởi động MySQL với skip-grant-tables
----------------------------------------
Mở Command Prompt và chạy:

  cd C:\xampp\mysql\bin
  mysqld.exe --skip-grant-tables --console

(Để cửa sổ này mở, đừng đóng)

BƯỚC 3: Mở Command Prompt MỚI và kết nối
----------------------------------------
Mở Command Prompt MỚI (giữ cửa sổ cũ) và chạy:

  cd C:\xampp\mysql\bin
  mysql.exe -u root

BƯỚC 4: Chạy các lệnh SQL
----------------------------------------
Trong MySQL prompt (mysql>), copy và paste các lệnh từ file:
  backend/fix-permissions-quick.sql

Hoặc chạy trực tiếp:

  FLUSH PRIVILEGES;
  DELETE FROM mysql.user WHERE User='root' AND Host='localhost';
  DELETE FROM mysql.user WHERE User='root' AND Host='127.0.0.1';
  CREATE USER 'root'@'localhost' IDENTIFIED BY '';
  CREATE USER 'root'@'127.0.0.1' IDENTIFIED BY '';
  GRANT ALL PRIVILEGES ON *.* TO 'root'@'localhost' WITH GRANT OPTION;
  GRANT ALL PRIVILEGES ON *.* TO 'root'@'127.0.0.1' WITH GRANT OPTION;
  FLUSH PRIVILEGES;
  exit;

BƯỚC 5: Dừng MySQL skip-grant-tables
----------------------------------------
- Đóng cửa sổ đang chạy mysqld.exe --skip-grant-tables
- Hoặc chạy: taskkill /F /IM mysqld.exe

BƯỚC 6: Khởi động lại MySQL bình thường
----------------------------------------
- Mở XAMPP Control Panel
- Click "Start" cho MySQL service

BƯỚC 7: Thử lại server
----------------------------------------
  npm run dev
