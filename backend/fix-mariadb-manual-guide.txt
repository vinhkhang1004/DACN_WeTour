========================================
HƯỚNG DẪN SỬA LỖI MARIADB THỦ CÔNG
========================================

Lỗi: "Host 'localhost' is not allowed to connect to this MariaDB server"

GIẢI PHÁP 1: Sử dụng --skip-grant-tables
----------------------------------------

1. Mở XAMPP Control Panel
2. Dừng MySQL service (Stop)
3. Mở Command Prompt hoặc XAMPP Shell
4. Chạy lệnh sau:

   cd C:\xampp\mysql\bin
   mysql.exe --skip-grant-tables --user=root

5. Trong MySQL prompt, chạy các lệnh sau:

   USE mysql;
   
   -- Xóa các user cũ có vấn đề
   DELETE FROM user WHERE User='root' AND Host='localhost';
   DELETE FROM user WHERE User='root' AND Host='127.0.0.1';
   
   -- Tạo lại user root
   INSERT INTO user (Host, User, Password, Select_priv, Insert_priv, Update_priv, Delete_priv, Create_priv, Drop_priv, Reload_priv, Shutdown_priv, Process_priv, File_priv, Grant_priv, References_priv, Index_priv, Alter_priv, Show_db_priv, Super_priv, Create_tmp_table_priv, Lock_tables_priv, Execute_priv, Repl_slave_priv, Repl_client_priv, Create_view_priv, Show_view_priv, Create_routine_priv, Alter_routine_priv, Create_user_priv, Event_priv, Trigger_priv) 
   VALUES ('localhost', 'root', '', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y');
   
   INSERT INTO user (Host, User, Password, Select_priv, Insert_priv, Update_priv, Delete_priv, Create_priv, Drop_priv, Reload_priv, Shutdown_priv, Process_priv, File_priv, Grant_priv, References_priv, Index_priv, Alter_priv, Show_db_priv, Super_priv, Create_tmp_table_priv, Lock_tables_priv, Execute_priv, Repl_slave_priv, Repl_client_priv, Create_view_priv, Show_view_priv, Create_routine_priv, Alter_routine_priv, Create_user_priv, Event_priv, Trigger_priv) 
   VALUES ('127.0.0.1', 'root', '', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y', 'Y');
   
   FLUSH PRIVILEGES;

6. Thoát MySQL (gõ: exit)
7. Khởi động lại MySQL service trong XAMPP Control Panel


GIẢI PHÁP 2: Sử dụng GRANT (Đơn giản hơn)
------------------------------------------

1. Mở XAMPP Control Panel
2. Dừng MySQL service
3. Mở Command Prompt:
   
   cd C:\xampp\mysql\bin
   mysql.exe --skip-grant-tables --user=root

4. Trong MySQL prompt:

   FLUSH PRIVILEGES;
   CREATE USER IF NOT EXISTS 'root'@'localhost' IDENTIFIED BY '';
   CREATE USER IF NOT EXISTS 'root'@'127.0.0.1' IDENTIFIED BY '';
   GRANT ALL PRIVILEGES ON *.* TO 'root'@'localhost' WITH GRANT OPTION;
   GRANT ALL PRIVILEGES ON *.* TO 'root'@'127.0.0.1' WITH GRANT OPTION;
   FLUSH PRIVILEGES;
   exit;

5. Khởi động lại MySQL service


GIẢI PHÁP 3: Sửa file cấu hình
--------------------------------

1. Mở file: C:\xampp\mysql\bin\my.ini
2. Tìm dòng [mysqld]
3. Đảm bảo có các dòng sau:

   [mysqld]
   bind-address = 127.0.0.1
   skip-networking = 0

4. Lưu file
5. Khởi động lại MySQL service


GIẢI PHÁP 4: Reset hoàn toàn (Nếu các cách trên không được)
------------------------------------------------------------

1. Dừng MySQL trong XAMPP
2. Backup thư mục: C:\xampp\mysql\data (nếu có dữ liệu quan trọng)
3. Xóa thư mục: C:\xampp\mysql\data
4. Khởi động lại MySQL - nó sẽ tự tạo lại database system
5. Sau đó chạy lại các lệnh GRANT ở trên

LƯU Ý: Giải pháp 4 sẽ XÓA TẤT CẢ DỮ LIỆU trong database!
